# 🌟 RPGタスク管理アプリ - あなたの成長物語 🌟

タスクをRPG風に管理できる素敵なアプリケーション！タスクを完了すると、あなたのパラメーターが成長していきます。

## 🎮 特徴

- **6つの成長パラメーター**: 知力、魅力、財力、体力、創造力、社交力
- **タスクタイプ別成長**: 6種類のタスクタイプで異なるパラメーターが成長
- **レベルアップシステム**: パラメーターがレベルアップすると演出付きでお祝い
- **パステルカラーデザイン**: 優しい色合いで目に優しいUI
- **データ永続化**: ブラウザにデータが保存される
- **レスポンシブ対応**: スマートフォンでも使いやすい

## 🎯 パラメーター詳細

| パラメーター | 主な成長タスク | 説明 |
|------------|---------------|------|
| 🧠 知力 | 勉強、仕事 | 学習能力や問題解決能力 |
| ✨ 魅力 | 創作、社交 | 人格的魅力やコミュニケーション能力 |
| 💰 財力 | 仕事、生活 | 経済力や資産管理能力 |
| 💪 体力 | 運動、生活 | 身体的健康や持久力 |
| 🎨 創造力 | 創作、勉強 | アイデア発想や表現力 |
| 🤝 社交力 | 社交、仕事 | 人間関係やチームワーク |

## 📝 タスクタイプと経験値

- **📚 勉強**: 知力+30, 創造力+10, 魅力+5
- **💼 仕事**: 財力+25, 知力+15, 社交力+10
- **🏃 運動**: 体力+35, 魅力+10, 知力+5
- **🎨 創作**: 創造力+30, 魅力+15, 知力+10
- **👥 社交**: 社交力+30, 魅力+20, 知力+5
- **🏠 生活**: 体力+15, 財力+10, 知力+5

## 🚀 使い方

1. **タスクを追加**: 「新しいクエスト」欄にタスク名を入力し、タイプを選択して「+」ボタンをクリック
2. **タスクを完了**: タスクリストの「完了！」ボタンをクリック
3. **成長を確認**: パラメーターが成長し、レベルアップするとお祝いメッセージが表示
4. **継続的に成長**: 日々のタスクをこなして、理想の自分を目指そう！

## 🎨 デザインコンセプト

- **配色**: パステルカラー（淡いブルー、ピンク、ミントグリーンなど）
- **形状**: 全ての要素を丸くして柔らかい印象
- **フォント**: 丸文字っぽいゴシック体（Noto Sans JP）
- **余白**: ゆったりとしたレイアウトでリラックスした雰囲気

## 💾 データ管理

- ブラウザのlocalStorageにデータを自動保存
- データはローカル環境に保存され、プライバシーを保護
- デバッグモード（URLに `#debug` を追加）でデータリセット可能
